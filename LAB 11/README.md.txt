Отчет по программе расчета сложных процентов

Описание программы:
Программа рассчитывает итоговую сумму вклада по формуле сложных процентов с возможностью ежемесячного начисления процентов.
Также предусмотрено логирование ошибок в отдельный файл errors.log и запись результатов в файл result.txt.

Файлы:

result.txt — хранит результаты расчета.

errors.log — хранит ошибки с отметкой времени.


Входные данные

Параметр	Значение

Вклад (P)	100000 тг
Ставка (r)	12%
Срок (t)	3 года



Расчет

Формула сложных процентов:

S = P \times \left(1 + \frac{r}{n}\right)^{n \cdot t}

n = 12 (начисление ежемесячно)

Перевод ставки в доли: 


Результат:

S = 142576.64 \text{ тг}



Результаты работы программы

Вывод на экран:


Итоговая сумма через 3 лет: 142576.64 тг
Работа программы завершена.
Программа завершена.

Запись в result.txt:


Вклад: 100000 тг
Ставка: 12.0%
Срок: 3 лет
Итоговая сумма: 142576.64 тг


Ошибки, зафиксированные в errors.log

2025-10-29 13:25:31,456 - ERROR - Ошибка при расчете: Все значения должны быть положительными.
2025-10-29 13:25:31,456 - ERROR - Ошибка при расчете: Все значения должны быть положительными.

Причина:
Ошибка возникает при вводе некорректных или нулевых значений. В данном запуске программа фиксировала двойное логирование одной и той же ошибки.
