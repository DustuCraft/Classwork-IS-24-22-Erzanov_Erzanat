Консольное приложение для управления списком студентов, созданное с использованием ООП.
Поддерживает добавление, просмотр, редактирование и сохранение данных в JSON.

Функционал
Добавление студента (Имя, Группа, GPA)
Просмотр всех студентов
Редактирование выбранного студента (Имя / Группа / GPA)
Сохранение данных в:
students.json — полный список
students_update.json — обновлённые данные

Структура классов
Student
Инкапсулированные поля: __name, __group, __gpa
Методы:
display_info()
update_gpa()
геттеры/сеттеры
Group

Методы:
add_student()
show_all()
edit_student()
save_to_file()
save_updates()
